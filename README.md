# Energy Detective AI

An educational Python + Streamlit project that simulates a smart-home energy investigator.

## Features
- Select one of six simulated energy scenarios.
- Estimate energy cost before and after scheduling.
- Compare hourly load and electricity prices.
- Review the agent's decision log.
- Export a JSON report and hourly CSV.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Upload these files to a GitHub repository, then deploy the repository using Streamlit Community Cloud. Choose `app.py` as the main file.

## Important
This is a transparent, rule-based educational agent using simulated data. It does not connect to real smart meters, control appliances, or guarantee real-world savings.
